Penjelasan Sistem Backend Aplikasi Mediku

Dokumen penjelasan teknis untuk rencana migrasi ke server kampus · Aplikasi Mediku (Media Informasi dan Diagnostik Kesehatanku)

Bagian 1 — Penjelasan Sederhana untuk Bapak/Ibu Dosen

Aplikasi Mediku terdiri dari dua bagian:

1. Aplikasi di HP — yang dipakai pasien, admin, dan petugas kesehatan. Ini bagian yang terlihat di layar.

2. Backend (server) — "otak" di belakang layar. Inilah yang kita bahas. Backend tidak terlihat oleh pengguna, tetapi tugasnya menyimpan semua data (akun, data kesehatan, jadwal, artikel) dan melayani setiap permintaan dari aplikasi HP.

Analogi sederhana: jika aplikasi HP itu seperti kasir di depan toko, maka backend adalah gudang dan pembukuan di belakang. Pasien menekan tombol di HP → permintaan dikirim ke backend → backend mengambil atau menyimpan data → lalu mengirim balik hasilnya ke HP.

Saat ini backend sudah berjalan dan online di server sewaan (DigitalOcean), lengkap dengan alamat domain sendiri dan koneksi aman (HTTPS / gembok hijau). Yang kita inginkan sekarang adalah memindahkan sistem yang sudah berjalan ini ke server kampus, tanpa mengubah cara kerjanya.

Hal penting yang memudahkan: seluruh sistem ini sudah "dikemas rapi" menggunakan teknologi bernama Docker. Artinya sistem ini seperti peti kemas pindahan — bisa diangkat dari satu server ke server lain dan langsung berjalan sama persis, tanpa perlu memasang ulang satu per satu. Ini sangat memudahkan tim teknis kampus.

Bagian 2 — Spesifikasi Teknis untuk Tim Teknis Kampus

Arsitektur Sistem

Sistem berjalan dalam 3 kontainer Docker yang diatur oleh Docker Compose:

KontainerFungsiPort
nginxPintu depan / reverse-proxy. Mengurus HTTPS (SSL), menyajikan file gambar, caching, dan meneruskan permintaan ke backend.80 (HTTP) & 443 (HTTPS) — menghadap internet
backendServer aplikasi (API). Memproses semua logika: login, data kesehatan, jadwal, dan lainnya.3000 — internal saja, tidak langsung ke internet
postgresDatabase. Menyimpan seluruh data secara permanen.5432 — internal saja

Hanya nginx yang terbuka ke internet. Backend dan database tersembunyi di belakangnya, sehingga lebih aman.

Database

PostgreSQL berisi 9 tabel utama: User (akun), FamilyProfile (profil anggota keluarga), HealthMetric (data ukur kesehatan), MedicalScreening (skrining medis), Appointment (jadwal janji temu), Article (artikel kesehatan), Region (data wilayah), Notification (notifikasi), dan TokenBlacklist (token login yang dicabut).

Data tersimpan di volume Docker permanen, sehingga tidak hilang meskipun kontainer di-restart.

Catatan Migrasi ke Server Kampus

Karena seluruh sistem sudah berbasis Docker, proses pemindahan pada dasarnya: pasang Docker di server kampus → salin kode dan konfigurasi → jalankan. Sistem akan berjalan identik dengan yang sekarang. Yang perlu disiapkan pihak kampus pada umumnya adalah server Linux dengan Docker, akses port 80 & 443 ke internet, serta sebuah domain/subdomain beserta sertifikat SSL-nya.
